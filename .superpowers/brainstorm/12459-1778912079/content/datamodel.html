Thiết kế Phần 2: Cấu trúc Dữ liệu

Chi tiết Schema và Metadata linh hoạt

PostgreSQL Schema (questions table)
CREATE TABLE questions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    content TEXT NOT NULL,
    type VARCHAR(20) NOT NULL, -- mcq, essay
    options JSONB, -- For MCQ choices
    answer TEXT, -- Correct ID or Sample Text
    metadata JSONB DEFAULT '{}', -- Flexible tags
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- GIN Index for fast searching in metadata
CREATE INDEX idx_questions_metadata ON questions USING GIN (metadata);
Sample JSONB Metadata
{
  "subject": "Mathematics",
  "grade": 12,
  "difficulty": "Advanced",
  "chapter": "Calculus",
  "topic": "Integrals",
  "author": "Admin",
  "source": "Final Exam 2024"
}

Bạn có thể thêm bất kỳ cặp Key-Value nào vào đây mà không cần đổi Schema.
